## :house: Sobre o Projeto

<p align="justify">
O <strong>Wide Coverage Location</strong> representa a versão final de um projeto desenvolvido anteriormente, agora aprimorado como o primeiro desafio prático de CSS do DevClub, com adaptação para computadores e dispositivos móveis.
</p>

<p align="justify">
O projeto consiste em uma landing page moderna que simula um serviço de mobilidade, com foco em layout, posicionamento de elementos e responsividade para diferentes dispositivos.
</p>

Diferenciais:
- Versão desktop e mobile
- Uso de Flexbox
- Estrutura organizada de layout
- Design inspirado em interfaces modernas
